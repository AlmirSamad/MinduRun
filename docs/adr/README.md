# Architecture Decision Records

Use ADRs only if the project makes a long-lived architectural change.

Examples:
- deciding to add persistence;
- deciding to add a backend;
- replacing Riverpod;
- changing scoring semantics.

Template:

```md
# ADR-XXXX — Title

## Status
Proposed | Accepted | Superseded

## Context
Why is a decision needed?

## Decision
What are we choosing?

## Consequences
What becomes easier/harder?

## Alternatives considered
What did we reject?
```
